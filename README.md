# little-prince-reading-room

A fact-checked reading log for classic literature.

This repository collects carefully verified records of classic books — starting with
Antoine de Saint-Exupéry's *The Little Prince*. Every value in each record (title,
author, dates, publishers, identifiers, edition counts, cover images) comes from a
live catalog lookup against [Open Library](https://openlibrary.org), never from memory,
and is cross-checked before it is recorded.
